# Ppois_1 — классы Polynomial и Set на C++

Лабораторная работа по ООП на C++: реализация двух классов с перегрузкой операторов, unit-тесты на UnitTest++, консольное меню для ручной проверки и документация Doxygen.

## Классы

### Polynomial
Многочлен с вещественными коэффициентами (коэффициенты хранятся от младшего к старшему).

- конструкторы: по степени, из массива коэффициентов, копирования;
- арифметика: `+`, `-`, `*`, `/` (частное, остаток отбрасывается) и `+=`, `-=`, `*=`, `/=`;
- вычисление значения в точке по схеме Горнера: `p(x)`;
- доступ к коэффициентам: `p[i]` (при выходе за границы бросает `std::out_of_range`);
- сравнение `==`, `!=`, присваивание `=`;
- ввод/вывод через `>>` и `<<`;
- автоматическая нормализация (удаление нулевых старших коэффициентов);
- деление на нулевой многочлен бросает `std::invalid_argument`.

### Set
Множество строк и вложенных множеств. Элементы хранятся без повторов и в отсортированном порядке.

- создание из строки вида `{a, b, {c, d}}` (внешние скобки необязательны);
- `add`, `size`, `empty`;
- сравнение `==`, `!=` (не зависит от порядка элементов);
- вложенные множества любой глубины;
- ввод/вывод через `>>` и `<<`.

## Требования

- компилятор с поддержкой C++14 (g++, clang, MSVC);
- CMake 3.10 или новее;
- UnitTest++;
- Doxygen и Graphviz (для документации, необязательно).

Установка на Ubuntu/Debian:

```bash
sudo apt install build-essential cmake libunittest++-dev doxygen graphviz
```

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

После изменения кода достаточно повторить вторую команду. Повторно запускать первую нужно только после изменения `CMakeLists.txt` или добавления файлов.

## Запуск

Программа с меню:

```bash
./build/menu
```

Unit-тесты:

```bash
./build/tests
```

Собрать и запустить только одну часть:

```bash
cmake --build build --target tests && ./build/tests
cmake --build build --target menu  && ./build/menu
```

## Тесты

Тесты написаны на библиотеке UnitTest++ (более 100 тестов на оба класса). Они проверяют:

- конструкторы, копирование и присваивание;
- доступ по индексу и граничные случаи;
- арифметику, деление и вычисление значения;
- сравнение, ввод и вывод;
- исключения при ошибочных операциях;
- разбор строк, вложенные множества, удаление повторов и порядок элементов в `Set`.

Успешный запуск заканчивается строкой `Success: N tests passed.`

## Меню

Главное меню позволяет выбрать класс для проверки.

**Polynomial.** Многочлены A и B вводятся в формате «степень, затем коэффициенты от свободного члена к старшему»:

```
2 1 2 3        →  3x^2 + 2x + 1
```

Доступны сложение, вычитание, умножение, деление, значение в точке, составные операторы, сравнение, присваивание и чтение/изменение коэффициентов `A[i]`.

**Set.** Множества вводятся строкой:

```
{a, b, {c, d}, {}}
```

Доступны добавление атома или подмножества, размер, проверка на пустоту, сравнение, присваивание и копирование.

Все исключения перехватываются и выводятся на экран. Выход из любого меню — пункт `0`.
